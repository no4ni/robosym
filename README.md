# robosym

3D-симулятор мобильного робота (R2-D2) в интерьере квартиры на базе **PyBullet** с лидаром, компасом, виртуальным GPS и окном камеры первого лица (**Robot View**).

Вынесен из [no4ni/anyjson](https://github.com/no4ni/anyjson) в отдельный репозиторий, чтобы основной движок оставался компактным.

## Возможности
- **Физика и навигация:** движение (`forward`), повороты (`turn`), сброс позиции (`reset`) с проверкой столкновений со стенами и мебелью (`hatacol.obj`).
- **Сенсоры:** 7-лучевой лидар, компас, координаты GPS и трансляция телеметрии в `telemetry.json`.
- **Две камеры:** обзорная камера сцены (PyBullet GUI) + независимый рендер с головы робота (`Robot View (Camera RGB)` через OpenCV).
- **Два режима управления:** интерактивно через консоль или асинхронно через JSON-файл команд (`SIM_CMD_FILE` / `command.json`).

## Установка и автономный запуск

    git clone https://github.com/no4ni/robosym.git
    cd robosym
    pip install -r requirements.txt
    python hatasim2.py

Консольные команды в автономном режиме:
- `fwd 0.2` — шаг вперёд на 0.2 м
- `turn 0.5` — поворот на 0.5 рад
- `reset` — возврат на стартовую точку
- `quit` / `exit` — выход

## Подключение к `anyjson`

1. Склонируйте репозиторий в любую удобную папку (например, `E:\Jericho\Private\projects\robosym`).
2. Укажите путь к папке симулятора в `side/config.json` проекта `anyjson`:

    {
      "sim_dir": "E:/Jericho/Private/projects/robosym"
    }

После этого агенту в `anyjson` станут доступны команды управления роботом: `сим_запустить`, `сим_статус`, `сим_вперёд`, `сим_повернуть`, `сим_сброс`, `сим_команда`, `сим_остановить`.
